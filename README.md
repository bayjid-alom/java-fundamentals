<details>
<summary><b>📌 Important Notes</b></summary>

### `.java`

- Source Code
- Human-readable Java file

### `.class`

- Compiled Bytecode
- Generated by `javac`

### `javac`

- Java Compiler
- Converts `.java` → `.class`

### `java`

- JVM Runtime
- Executes the compiled `.class` file

### Remember

- Every code change requires recompilation.
- File name and **public class name** must be identical.
- Never run using `.java`.

✅ Correct

```bash
java HelloWorld
```

❌ Wrong

```bash
java HelloWorld.java
```

</details>

## ☕ Java-এর সাথে কফি কাপের সম্পর্ক কীভাবে তৈরি হলো?

জাভা (Java) প্রোগ্রামিং ভাষার নামকরণ এবং এর কফি কাপের লোগোটি ইন্দোনেশিয়ার বিখ্যাত **'জাভা' দ্বীপের কফি** এবং ডেভেলপারদের **কফি পানের সংস্কৃতির** সাথে সরাসরি সম্পর্কিত।

জেমস গসলিং ও তাঁর টিম (**Sun Microsystems**) যখন ভাষাটি তৈরি করেন, তখন অতিরিক্ত কফি পান তাঁদের কাজের জ্বালানি ছিল। নাম পরিবর্তনের সময় কফি থেকে অনুপ্রাণিত হয়ে এর নাম রাখা হয় এবং লোগোতে কফি কাপ ব্যবহার করা হয়।

---

### 🌱 মূল কারণসমূহ

### ☕ নামকরণের উৎস

ভাষাটির প্রাথমিক নাম **'Oak'** বা **'Green'** পরিবর্তনের পর, কফি পানের সময় মাথায় আসা নাম থেকে ইন্দোনেশিয়ার **জাভা দ্বীপের কফির নামানুসারে** একে **'Java'** রাখা হয়।

---

### 💻 ডেভেলপার সংস্কৃতি

দীর্ঘ রাত জেগে কোডিং করার পেছনে কফির বড় অবদান থাকে। ডেভেলপারদের এই জীবনধারাকে শ্রদ্ধা জানাতেই লোগোতে কফি কাপ রাখা হয়েছে।

---

### ⚡ প্রতীকী শক্তি

কফি যেমন শরীর ও মনে চাঞ্চল্য ও শক্তি জোগায়, তেমনি জাভাও একটি গতিশীল ও কার্যকরী প্রোগ্রামিং ভাষা—এটি বোঝাতেই **বাষ্প ওঠা কফি কাপ প্রতীকটি** বেছে নেওয়া হয়েছিল।
